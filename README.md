# 🐍 Bases de Python en 16 Días

> **Autor:** J Alexis Tenorio Hernandez

Un curso práctico y progresivo que cubre los fundamentos de Python, desde conceptos básicos hasta programación orientada a objetos y manejo avanzado de módulos.

---

## 📚 Estructura del Proyecto

El proyecto se divide en "días", donde cada día aborda diferentes conceptos desde lo más básico hasta lo más avanzado:

### **Día 2** - Comisiones y Primeras Operaciones
- Cálculo de comisiones
- Operaciones básicas

### **Día 3** - Estructuras de Datos Fundamentales
- Strings
- Listas
- Tuplas
- Diccionarios
- Sets
- Booleanos

### **Día 4** - Control de Flujo
- Operadores
- Sentencias if/else
- Bucles for
- Bucles while
- Match (pattern matching)
- Comprensión de listas
- Min/Max
- Zip
- Módulo random

### **Día 5** - Funciones
- Definición y uso de funciones
- Argumentos indefinidos (*args)
- Ejercicios prácticos
- Proyecto: Juego del Ahorcado

### **Día 6** - Manejo de Archivos y Rutas
- Lectura y escritura de archivos
- Módulo os
- Pathlib
- Proyecto: Gestor de Recetas

### **Día 7** - Programación Orientada a Objetos (POO)
- Clases y objetos
- Herencia
- Polimorfismo
- Métodos especiales
- Proyecto: Sistema de Cuenta Bancaria

### **Día 8** - Técnicas Avanzadas
- Decoradores
- Generadores
- Manejo de errores y excepciones
- Proyecto: Manejo de números

### **Día 9** - Módulos Estándar Avanzados
- Módulo math
- Expresiones regulares (re)
- Módulo collections
- Fecha y hora
- Medición de tiempo
- Compresión de archivos
- Proyecto: Extracción de archivos ZIP

### **Día 10** - Proyectos Integrados
- Aplicación completa: Invasion Espacial (juego)
- Generación de ejecutable (.spec)

---

## 🚀 Cómo Usar

1. **Clonar o descargar** el repositorio
2. **Navegar** a la carpeta del proyecto
3. **Ejecutar** los archivos Python:
   ```bash
   python nombre_archivo.py
   ```

### Requisitos
- Python 3.8+
- No hay dependencias externas (usa solo librerías estándar de Python)

---

## 📝 Notas
- Cada "día" es independiente y puede ser estudiado en cualquier orden (aunque se recomienda seguir la progresión)
- Los proyectos están en subcarpetas `Proyecto/` dentro de cada día
- Los ejercicios combinan práctica individual y proyectos integradores
